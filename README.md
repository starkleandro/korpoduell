# korpoduell
A competitive mobile quiz game with real-time duels, accounts, and persistent progression.

## 🎮 Features

- ⚔️ **Real-time 1v1 duels**  
- ♾️ **Endless singleplayer mode**  
- 🏆 **Monthly leaderboards**  
- 👤 **Persistent accounts and player statistics**  
- 🎨 **Fully custom UI/UX designed in Figma**  
- 🔌 **Low-latency communication over WebSockets**  
- 🚀 **Regular updates and new features planned** (alliances, events, and more)

---

## 🛠 Tech Stack

**Frontend**  
- React Native (Expo + EAS)

**Backend**  
- Python  
- Flask  
- python-socketio  
- Render.com (cloud hosting & deployment)

**Design**  
- Figma

---

## 🧩 Architecture Overview

Korpoduell uses a hybrid architecture combining REST and WebSockets:

- REST is used for authentication, account data, and statistics  
- WebSockets handle real-time matchmaking, game events, and score synchronization  
- The backend is hosted on Render with scalable infrastructure
